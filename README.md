# Insurance-Analytics
This project presents an Insurance Analytics Dashboard developed using SQL, Excel, Power BI, and Tableau to perform end-to-end data analysis. The objective of this project is to analyze insurance business performance, customer behavior, claim trends, and premium growth using modern Business Intelligence tools.
## Dataset used
- <a href="https://github.com/prajwalshivu912-ui/Insurance-Analytics/blob/main/Policy%20Data%20111.csv.xlsx">Dataset</a>

## Key KPIs
Total Policy Issued
Total Customers
Total Claim Amount
Premium Growth Rate
Policy Expire This Year
